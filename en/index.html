01About

Security through identity

My field is Microsoft environments: Active Directory, Microsoft Entra ID and Azure. I approach security through identity — who can access what, with which privileges, and how to prove it.

My background spans Windows infrastructure administration, migrations and cloud security. Seeing both the operational and the governance side lets me turn a technical finding into an action plan that makes sense to an engineering team as well as to a CISO.

I use PowerShell and automation as means to an end: making operations reproducible, traceable and less error-prone.

06Method

How I work

A simple, repeatable approach that links technical analysis to concrete decisions.

  1. 01

    Understand the existing

    Map identities, privileges, flows and dependencies before touching anything.

    → Inventory · Scope

  2. 02

    Assess the risks

    Measure posture objectively: audit tooling, configuration and permissions review.

    → Findings · Baseline

  3. 03

    Prioritise

    Rank actions by security impact and real effort, starting with Tier 0.

    → Action plan

  4. 04

    Remediate and automate

    Apply fixes in batches — scripted and reversible where possible.

    → GPOs · Scripts

  5. 05

    Measure and document

    Re-assess, report clearly and capture knowledge so security holds over time.

    → Metrics · Documentation
